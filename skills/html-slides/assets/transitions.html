html-slides

Slide transitions

Press → to see each one. T changes the theme, so you can see each theme's sweep colors. M changes the motion level.

Every slide here is entered with the transition it names.

Basic

fade

A cross-fade. Calm, and right for any deck.

data-transition="fade"

Basic

slide

The old slide pushes off and the new one pushes on. A good default for content.

data-transition="slide"

Basic

rise

The new slide floats up into place.

data-transition="rise"

Basic

zoom

Zooms through to the next slide.

data-transition="zoom"

Basic

wipe

A straight edge wipes across.

Basic

morph

Elements with the same data-morph name glide from one slide to the next, like PowerPoint's Morph.

Reveal

iris

A circle opens from where you clicked (or the side the slide comes from).

data-transition="iris"

Reveal

diagonal

A slanted edge cuts across.

data-transition="diagonal"

Reveal

split

Opens from the middle like doors.

data-transition="split"

Reveal

blinds

Venetian blinds open across the slide.

data-transition="blinds"

Reveal

cube

The deck turns like a cube.

data-transition="cube"

Motion graphics

panels

Three panels of color sweep across, one over another.

data-transition="panels"

Motion graphics

stripes

Diagonal bands of color race across.

data-transition="stripes"

Motion graphics

shutter

Columns drop like a shutter, then fall away.

data-transition="shutter"

Motion graphics

circle

Rings of color grow from the click, then open onto the slide.

data-transition="circle"

Motion graphics

tiles

Tiles pop in from one corner and out again.

data-transition="tiles"

Motion graphics

wave

A liquid wave of color rises through.

data-transition="wave"

data-transition="auto"

Each theme has its own

With auto, title, section and closing slides get the theme's signature sweep, statements and quotes get its reveal, and other slides get a quieter move. data-enter="cascade" brings each slide's content in piece by piece.
